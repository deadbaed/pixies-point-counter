# pixies-point-counter

Web app to keep score during a game of [Pixies](https://studiobombyx.com/en/jeu/pixies/).

Not affiliated with the game or the company behind it.

## Disclaimer

This was vibe coded, so the code is sloppy.

I initially wrote a list of stuff to do taken from the game rules, then gave it to the `Big Pickle` model from [OpenCode](https://opencode.ai/), and I told it when it did mistakes.

I always wanted to do a project with [Solid](https://www.solidjs.com/). Ironically, now I have a project with Solid, but I did not write a single line of code. Maybe I'll come back to improve things, because the code must not be very good.

I wrote this because I wanted to have a quick way to keep score of the game, and to see what vibe coding was like. Now from what I've seen about vibe coding: it does the job okay-ish, in the sense that the final results works, but the code must not be of good quality. It's fine for a small project like this which does not have a lot of business logic, but not for bigger and more importants projects.
